# Обзор архитектуры

Careeria — платформа для кандидатов, рекрутеров, нанимающих руководителей и администраторов компаний. Схемы описывают целевую архитектуру проекта.

## Как читать модель

1. [Контекст системы](context/system-context.md) — пользователи и внешние системы, C4 L1.
2. [Верхнеуровневый обзор](projections/high-level.md) — основные контейнеры и путь запроса, C4 L2.
3. [Полная система](container/full-system.md) — сервисы, данные и инфраструктура.
4. [Тематические проекции](projections/README.md) — отдельные домены и способы взаимодействия.
5. [Сценарии](dynamic/README.md) — порядок запросов и событий.

## Ответственность команды

[Области участников](projections/members/README.md) сохраняют отдельные представления L1/L2. [Командная интеграция](integration/team.md) объединяет их в одну модель.

Уровень C4 задаёт глубину описания, а проекция выбирает часть модели. Несколько диаграмм одного уровня позволяют раскрыть разные темы без перегрузки общей схемы.

SVG сохраняет пропорции. Ссылки на элементах позволяют перейти к связанным представлениям. Масштаб просмотра можно менять средствами браузера.
