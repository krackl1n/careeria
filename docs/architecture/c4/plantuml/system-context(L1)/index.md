# Контекст системы (L1)

Careeria связывает кандидатов и команды работодателей. Диаграмма показывает границу системы, четыре роли пользователей и внешние зависимости.


## Уровни L1 и L2 {#l2-views}

Контекст (L1) показывает границу Careeria, роли пользователей и внешние системы. Контейнерные представления (L2) раскрывают приложения, сервисы и хранилища внутри этой границы.

## Что показано

- Кандидат работает с профилем, вакансиями и процессом найма.
- Рекрутер, нанимающий руководитель и администратор компании участвуют в найме и управлении компанией.
- Identity Provider обеспечивает внешнюю аутентификацию; Notification Providers доставляют уведомления; Employer HR System обменивается данными с платформой.
