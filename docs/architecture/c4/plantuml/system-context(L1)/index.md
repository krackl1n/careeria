# Контекст системы (L1)

<!-- excerpt -->

В Careeria кандидаты откликаются на вакансии, рекрутеры ведут подбор, нанимающие руководители оценивают кандидатов, а администраторы управляют компаниями и ролями. Платформа использует внешние сервисы для входа и доставки уведомлений и обменивается данными о найме с кадровой системой работодателя.

Граница системы объединяет функции подбора персонала от публикации вакансии до принятия предложения. Пользовательские роли обращаются к платформе через веб-интерфейс. Провайдер входа, поставщики уведомлений и кадровая система работодателя обеспечивают внешние функции, с которыми Careeria обменивается данными по указанным протоколам.

<p align="right">Таблица - Элементы. Пользователи Careeria и внешние системы</p>

| Элемент | Тип или технология | Назначение и ответственность |
|---|---|---|
| Кандидат | Пользователь | Ищет работу, откликается на вакансии и проходит процесс найма. |
| Рекрутер | Пользователь | Публикует вакансии и ведёт кандидатов по процессу найма. |
| Нанимающий руководитель | Пользователь | Участвует в собеседованиях, оценке кандидатов и принятии решений. |
| Администратор компании | Пользователь | Управляет компанией, пользователями и ролями. |
| Identity Provider | Система | Внешний провайдер удостоверения личности на базе Keycloak. Identity Service использует OAuth 2.0 и OIDC для федеративного входа и связывания внешней учётной записи с пользователем Careeria. |
| Notification Providers | Система | Внешние поставщики доставки сообщений. SendGrid обрабатывает email, Firebase Cloud Messaging доставляет push, Twilio отправляет SMS по запросам сервиса уведомлений. |
| Employer HR System | Система | Кадровая система работодателя. Принимает результаты найма из Careeria и передаёт изменения кадровых данных через согласованные вебхуки. |
| Careeria | Система | Ведение вакансий, откликов, оценки и коммуникаций. |

<p align="right">Таблица - Связи. Пользователи Careeria и внешние системы</p>

| Источник | Получатель | Содержание взаимодействия | Протокол или способ вызова |
|---|---|---|---|
| Кандидат | Careeria | Ищет вакансии и откликается. | HTTPS |
| Рекрутер | Careeria | Управляет вакансиями и кандидатами. | HTTPS |
| Нанимающий руководитель | Careeria | Оценивает кандидатов. | HTTPS |
| Администратор компании | Careeria | Управляет компанией и ролями. | HTTPS |
| Careeria | Identity Provider | Аутентифицирует пользователей. | OAuth 2.0 / OIDC |
| Careeria | Notification Providers | Доставляет уведомления. | Email / Push / SMS |
| Careeria | Employer HR System | Обменивается данными найма. | HTTPS / REST / Webhooks |
