# Web Application (L3)

<!-- excerpt -->

Интерфейс React работает в браузере. Серверный BFF обрабатывает пользовательскую сессию и обращается к API Gateway. Страницы и BFF развёртываются вместе в одном приложении Next.js.

Маршруты Next.js готовят первоначальное представление страницы, а React обрабатывает действия пользователя в браузере. Серверный BFF восстанавливает контекст сессии, проверяет CSRF и вызывает API Gateway. Клиенты событий и медиа поддерживают подключения к Centrifugo и LiveKit. Загрузка файлов выполняется браузером по ограниченной ссылке, полученной через API.

<p align="right">Таблица - Элементы. Компоненты Web Application</p>

| Элемент | Тип или технология | Назначение и ответственность |
|---|---|---|
| Маршруты страниц | Next.js App Router / SSR | Выбирают страницу по адресу и формируют первоначальное представление для браузера. Для защищённых данных обращаются к серверному слою приложения. |
| Интерфейс пользователя | React / TypeScript | Обрабатывает ввод, отправляет команды серверу и обновляет отображение. Загружает файлы по ограниченным ссылкам, полученным через API. |
| Серверный BFF | Next.js | Принимает команды интерфейса, использует контекст сессии и передаёт авторизованные запросы в API Gateway. Возвращает данные в форме, подходящей для страницы. |
| Управление сессией | Next.js / HTTP cookies | Восстанавливает серверный контекст по защищённой cookie, проверяет CSRF для изменяющих запросов и предоставляет BFF токен доступа. |
| Клиенты событий и медиа | WebSocket / WebRTC | Подписываются на разрешённые каналы Centrifugo и подключаются к комнате интервью в LiveKit. События и состояние соединения передаются интерфейсу. |
| API Gateway | Go, grpc-gateway, grpc-go, OpenTelemetry | API Gateway принимает HTTP-запрос от BFF, проверяет предъявленный токен по открытым ключам Identity и применяет политику доступа к методу. Доменный сервис получает вызов по gRPC. |
| Centrifugo | Centrifugo, WebSocket, JWT | Сервис подключений браузеров и каналов обновления интерфейса. Принимает публикации Realtime Publisher и доставляет сообщения авторизованным подписчикам по WebSocket. |
| LiveKit | LiveKit, WebRTC, LiveKit React SDK | Медиасервер для интервью и Live Coding. Сервисы управляют комнатами через API, а браузеры участников передают аудио, видео и демонстрацию экрана через WebRTC. |
| Object Storage | MinIO, S3 API | Приватное объектное хранилище файлов на базе MinIO. File Service управляет версиями и ограниченными ссылками, а браузер передаёт содержимое по выданному разрешению. |

| Интерфейс пользователя | Object Storage | Передаёт файл по временной ссылке. Выполняется операция с содержимым или версией объекта в хранилище. | HTTPS / S3 API |
