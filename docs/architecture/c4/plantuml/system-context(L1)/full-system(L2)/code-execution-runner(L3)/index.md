# Code Execution Runner (L3)

<!-- excerpt -->

Code Execution Runner запускает решение и тесты в изолированной среде с ограничениями времени и памяти. Отчёт получает Assessment Service, который рассчитывает итоговый балл.

Входной компонент связывает задание с конкретной попыткой решения. Координатор выбирает среду языка и организует компиляцию и тестовые прогоны. Управление песочницей ограничивает время и память процесса и освобождает ресурсы после завершения. Компонент отчёта собирает результаты тестов и диагностику, после чего Assessment Service использует их при оценивании.

<p align="center">Рисунок - Компоненты Code Execution Runner</p>

<p align="right">Таблица - Элементы. Компоненты Code Execution Runner</p>

| Элемент | Тип или технология | Назначение и ответственность |
|---|---|---|
| Приём заданий | gRPC / Protobuf | Связывает задание с идентификатором операции и попыткой решения. Возвращает Assessment Service отчёт именно об этой попытке. |
| Координатор проверки | Управление исполнением | Выбирает среду для указанного языка, передаёт исходный код и тесты на исполнение. Различает ошибку компиляции, неуспешный тест и технический сбой среды. |
| Управление песочницей | Docker / gVisor | Создаёт временную среду, применяет ограничения времени и памяти, останавливает процесс при превышении лимитов и освобождает ресурсы после завершения. |
| Формирование отчёта | Обработка результатов | Объединяет статусы тестов, диагностику компиляции и показатели выполнения в отчёт для Assessment Service. |
| Assessment Service | Go / gRPC | Assessment Service управляет шаблонами заданий и попытками кандидатов. Для проверки кода он вызывает Code Execution Runner, затем рассчитывает балл и сохраняет результат в Assessment DB. |

Превышение лимита времени входит в результат проверки решения. Недоступность среды означает технический сбой запуска. Assessment Service сопоставляет отчёт с попыткой, сохраняет результат и применяет стратегию расчёта итогового балла.
