# Realtime Publisher (L3)

<!-- excerpt -->

Realtime Publisher читает события из Kafka, определяет канал получателя и публикует сообщение в Centrifugo. Centrifugo доставляет его в браузер по WebSocket.

Потребитель получает доменную запись и использует Schema Registry для чтения Avro. Следующий компонент отбирает поддерживаемое событие, определяет адресатов и составляет сообщение для канала. Клиент публикации обращается к HTTP API Centrifugo и возвращает результат обработки. После успешной публикации потребитель может подтвердить позицию Kafka, при повторной доставке событие может быть обработано снова.

<p align="right">Таблица - Элементы. Компоненты Realtime Publisher</p>

| Элемент | Тип или технология | Назначение и ответственность |
|---|---|---|
| Потребитель событий | Go / Kafka | Читает записи назначенных партиций и получает схему по идентификатору из Schema Registry. Отслеживает позицию обработки в группе потребителей. |
| Отбор событий и адресатов | Go | Отбирает поддерживаемые события и определяет канал по типу события и контексту получателя. Формирует сообщение с данными, разрешёнными для этого канала. |
| Клиент публикации | Go / HTTP | Передаёт имя канала и подготовленное сообщение в HTTP API Centrifugo. Возвращает результат публикации обработчику записи. |
| Kafka | Apache Kafka, KRaft | Событийная шина платформы. Хранит доменные сообщения в топиках и передаёт их группам потребителей для независимой асинхронной обработки. |
| Schema Registry | Apicurio Registry, Avro | Хранилище версий схем событий Avro на базе Apicurio Registry. Издатели и потребители получают схемы для сериализации и чтения доменных сообщений. |
| Centrifugo | Centrifugo, WebSocket, JWT | Сервис подключений браузеров и каналов обновления интерфейса. Принимает публикации Realtime Publisher и доставляет сообщения авторизованным подписчикам по WebSocket. |

|---|---|---|---|

| Отбор событий и адресатов | Клиент публикации | Передаёт канал и сообщение. Передаёт имя канала и подготовленное сообщение в HTTP API Centrifugo. Возвращает результат публикации обработчику записи. | Вызов внутри процесса |
| Клиент публикации | Centrifugo | Публикует в канал. | HTTP / JSON |
