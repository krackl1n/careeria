# Обзор архитектуры

Careeria — платформа для кандидатов, рекрутеров, нанимающих руководителей и администраторов компаний. Схемы описывают целевую архитектуру проекта.

## Как читать модель

1. [Контекст системы](system-context%28L1%29/index.md) — пользователи и внешние системы, C4 L1.
2. [Верхнеуровневый обзор](high-level%28L2%29/index.md) — основные контейнеры и путь запроса, C4 L2.
3. [Полная система](system-context%28L1%29/full-system%28L2%29/index.md) — сервисы, данные и инфраструктура.
4. [Тематические проекции](#projections) — отдельные домены и способы взаимодействия.
5. [Сценарии](dynamic/README.md) — порядок запросов и событий.

## Ответственность команды

[Области участников](members/README.md) сохраняют отдельные представления L1/L2. [Полная система](system-context%28L1%29/full-system%28L2%29/index.md) показывает общее контейнерное представление.

Уровень C4 задаёт глубину описания, а проекция выбирает часть модели. Несколько диаграмм одного уровня позволяют раскрыть разные темы без перегрузки общей схемы.

SVG сохраняет пропорции. Ссылки на элементах позволяют перейти к связанным представлениям. Масштаб просмотра можно менять средствами браузера.

## Навигация по уровням

Папки и меню повторяют одно дерево: «Контекст системы (L1)» → «Полная система (L2)» → сервис (L3) → компонент (L4). В каждой папке `index.md` открывает диаграмму, а дочерние папки содержат следующий уровень. В меню название не дублируется отдельным вложенным пунктом.

[System Landscape (L0)](landscape%28L0%29/README.md), [развёртывание](deployment/README.md) и [динамические сценарии](dynamic/README.md) имеют собственные папки. Тематические проекции имеют собственные папки, области участников находятся в `members/`.
