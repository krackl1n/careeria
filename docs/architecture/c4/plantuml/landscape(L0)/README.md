# System Landscape (L0)

Карта систем, участвующих в подборе и последующем кадровом учёте. Область схемы — взаимодействие Careeria с работодателями и внешними поставщиками. Это целевое представление архитектуры: оно не означает, что все интеграции уже реализованы.

## Как читать диаграмму

Сверху показаны кандидаты и команда работодателя. В середине — два независимых контура: Careeria и кадровая система работодателя. Ниже — внешние сервисы, которые Careeria использует для входа пользователей и доставки уведомлений. Стрелки описывают направление действий или передачи данных, а цвета и типы элементов объясняет легенда.

| Участник или система | Роль в экосистеме |
|---|---|
| Кандидат | Ищет вакансии, откликается и проходит отбор в Careeria. |
| Команда работодателя | Объединяет рекрутеров, нанимающих руководителей и администраторов компании. Использует Careeria для найма; кадровая система обслуживает кадровый учёт работодателя. Детальные роли раскрываются на L1. |
| Careeria | Платформа подбора: вакансии, отклики, оценивание, коммуникации и сопровождение процесса найма. |
| Employer HR System | Класс корпоративных кадровых систем работодателей. Принимает результаты найма и передаёт изменения в Careeria; конкретный продукт не зафиксирован. |
| Identity Provider | Внешняя аутентификация и федерация входа. В текущей модели используется OIDC-провайдер на базе Keycloak. Это отдельная зависимость, а внутренний Identity Service остаётся частью Careeria. |
| Notification Providers | Внешние поставщики доставки: SendGrid, Firebase Cloud Messaging и Twilio. На L0 объединены в одну группу систем; внутренний Notification Service остаётся частью Careeria. |

Граница «Контур Careeria» показывает нашу платформу, «Контур работодателя» — независимую внешнюю систему. Группа внешних сервисов объединяет зависимости по назначению и не означает общего владельца или размещения. Работа команды работодателя с HR-системой показана как бизнес-связь; конкретные роли и права в чужой системе эта модель не задаёт.

## Что раскрывается на следующем уровне

В проекте **L0** — обозначение [System Landscape](https://c4model.com/diagrams/system-landscape), дополнительного представления C4. Здесь рассматривается экосистема из нескольких систем. [Контекст системы (L1)](../system-context%28L1%29/index.md) выбирает Careeria и подробнее показывает её пользователей и непосредственные внешние зависимости.

На L0 не раскрываются внутренние микросервисы, хранилища, брокеры, протоколы и узлы размещения. Они описываются в [полной системе (L2)](../system-context%28L1%29/full-system%28L2%29/index.md) и отдельных диаграммах развёртывания. Порядок обмена с HR-системой раскрывается в [динамическом сценарии](../dynamic/hr-integration.md).

Нажмите на Careeria в диаграмме, чтобы открыть её **L1**. [Исходник PlantUML](system-landscape.puml) можно использовать для изменения схемы.
