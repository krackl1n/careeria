# 1.4. Задачи и функциональные возможности

Платформа Careeria покрывает полный цикл найма и решает следующие функциональные задачи:

## Ключевые функциональные блоки

| Блок | Функциональные возможности |
|---|---|
| **Профиль соискателя** | Ведение профиля кандидата, опыта работы, образования, навыков, языков, карьерных предпочтений и нескольких версий резюме |
| **Управление компаниями** | Регистрация компаний-работодателей, управление участниками и назначение корпоративных ролей |
| **Управление вакансиями** | Создание, публикация, приостановка, закрытие и архивация вакансий; настройка требований, условий и вилки компенсации |
| **Процесс найма (Pipeline)** | Отклики на вакансии, настраиваемые этапы отбора, строгая state machine переходов, назначение интервью, офферы, отказы и отзыв откликов |
| **Оценка кандидатов** | Шаблоны оценок, тесты с вопросами, практические задания, сессии Live Coding и расчёт итоговых баллов |
| **Коммуникации** | Личные диалоги «Кандидат ↔ Рекрутер», групповые чаты, чат комнаты интервью, вложения, реакции и статусы прочтения в реальном времени |
| **Видеособеседования** | Встроенные аудио- и видеоконференции (WebRTC), демонстрация экрана, управление участниками комнаты и запись встреч |
| **Хранение файлов** | Загрузка и скачивание резюме, портфолио, вложений чата, материалов заданий и записей собеседований через presigned URL |
| **Уведомления** | Многоканальная доставка событий найма (in-app, email, push, SMS) |
| **Аналитика и история** | Полный неизменяемый журнал переходов по этапам найма (`ApplicationTransition`) для расчёта времени прохождения воронки |
| **HR-интеграции** | Подписанные входящие и исходящие HTTPS webhooks для синхронизации с корпоративными HR-системами |
