# 2.3. Функциональное моделирование целевых процессов TO-BE на базе платформы Careeria

## Концепция целевого состояния процессов подбора

Целевая функциональная модель разработана с единой точки зрения пользователя в лице специалистов по подбору персонала и нанимающих руководителей, описывая бизнес-логику процесса найма без смешения с внутренней программной структурой. Пользователь взаимодействует с прикладными функциями системы через веб-интерфейс, тогда как программные компоненты платформы выступают внутренними элементами обеспечивающего механизма и подробно раскрываются в последующих разделах архитектурного проектирования. Модель устраняет фрагментацию инструментов за счет объединения сквозной воронки, единого экрана собеседования со встроенным видеозвонком, редактором кода и текстовым каналом, а также непрерывного цифрового аудита. При создании вакансии нанимающий менеджер сразу формирует стандартизированный чек-лист оценки, который затем сквозным образом используется для объективного скрининга и выставления баллов на техническом интервью. Встроенный чат используется для оперативного согласования слотов и отправки развивающего фидбека кандидатам, а видеосвязь служит основным каналом для живого обсуждения и защиты написанного кода.

## Архитектурное соответствие функциональной модели и программных сервисов платформы

Представленная функциональная модель отражает последовательность действий с точки зрения конечного пользователя, а фактическое исполнение данных операций обеспечивается распределенным комплексом микросервисов платформы Careeria. Начальный этап регистрации профиля компании и размещения вакансии опирается на функциональные возможности Company Service, отвечающего за администрирование профилей работодателей и ролевой доступ, а также Vacancy Service, который обеспечивает полный жизненный цикл заявок, публикацию требований и конфигурацию эталонных чек-листов оценки. Процедуры первичного сбора откликов, их автоматизированного скоринга и согласования кандидатов реализуются совместной работой Candidate Service для централизованного хранения анкет соискателей, Hiring Service для управления этапами канбан-воронки и Communication Service, предоставляющего защищенный текстовый канал для обсуждения организационных деталей и времени встречи. Проведение комплексного технического испытания в едином окне полностью поддерживается Assessment Service, который координирует медиапотоки видеосвязи, работу встроенного веб-редактора кода, запуск тестов в изолированных контейнерах и автоматическое сведение результатов в чек-листе, причем диалог по логике решения ведется напрямую через встроенный видеоканал. Финальный этап утверждения оффера и трудоустройства исполняется силами Hiring Service для генерации цифровых условий предложения, Communication Service для передачи развернутой обратной связи соискателю, а также специализированным интеграционным шлюзом 1C Integration Service для передачи учетных сведений финалиста в систему 1С:ЗУП без повторного ручного ввода данных со стороны кадровых специалистов.
