# 2. Концепт программного продукта

Глава 2 описывает процесс найма до и после внедрения Careeria. В центре модели — действия кандидата, рекрутера, нанимающего руководителя и администратора компании: подготовка вакансии, отбор откликов, интервью, решение и кадровое оформление. В целевом процессе отдельно показано, какие проблемы текущего порядка работы устраняются на каждом этапе.
