# 2. Бизнес-сервисы и доменная модель

Прикладная логика Careeria разделена на шесть доменных бизнес-сервисов с чёткими границами владения данными (bounded contexts):

1. **Candidate Service** — данные и резюме кандидата.
2. **Company Service** — организации-работодатели, участники и корпоративные роли.
3. **Vacancy Service** — описание, требования и жизненный цикл вакансий.
4. **Hiring Service** — центральный сервис процесса найма и владелец state machine откликов.
5. **Assessment Service** — тестирование, практические задания и Live Coding.
6. **Communication Service** — пользовательские диалоги, групповые чаты и сообщения.
