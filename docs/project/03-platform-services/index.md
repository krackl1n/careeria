# 3. Требования к ПО: классификация и влияние по методологии FURPS+DEEP

Глава 3 посвящена формализации, всесторонней классификации и оценке архитектурного влияния требований к программному обеспечению цифровой платформы подбора персонала **Careeria**. 

В основе спецификации требований лежит признанная в программной инженерии модель **FURPS+** (Robert Grady, Hewlett-Packard), дополненная расширенным контуром проектных и инфраструктурных ограничений **DIIP / DEEP** (*Design, Implementation, Interface, Physical*). Сформированный перечень требований служит фундаментом для составления Технического задания по ГОСТ 34.602-2020, проектирования микросервисной архитектуры в нотации C4 Model и планирования итеративной разработки.
