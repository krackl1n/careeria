# 3.2. Edge-уровень, Realtime и видеосвязь

## BFF (Backend for Frontend)

Промежуточный Go-сервис между браузерным приложением (Next.js) и внутренними микросервисами:

- управляет пользовательскими сессиями через защищённые `HttpOnly`/`Secure`/`SameSite` cookies (refresh token не доступен из JavaScript);
- обеспечивает CSRF-защиту и прозрачное обновление токенов;
- агрегирует данные из нескольких доменных сервисов и адаптирует DTO под потребности UI;
- не содержит бизнес-логики найма, вакансий или оценки.

---

## API Gateway

Единая точка входа во внутренний gRPC-контур:

- преобразует HTTP/JSON-запросы в gRPC через `grpc-gateway`;
- отвечает за маршрутизацию, rate limiting и лимиты запросов;
- проверяет аутентификационный контекст и пробрасывает метаданные трассировки (OpenTelemetry).

---

## Centrifugo (Realtime Transport)

Отвечает за доставку событий в браузер по WebSocket в реальном времени. Не является источником бизнес-данных.

**Примеры пользовательских событий:** `message.created`, `message.read`, `application.stage.changed`, `interview.started`, `assessment.updated`, `typing.started`.

```text
Backend Service / Realtime Publisher ──▶ Centrifugo ──(WebSocket)──▶ Frontend
```

---

## LiveKit (Видеоконференции)

Обеспечивает проведение онлайн-собеседований по WebRTC (аудио, видео, демонстрация экрана, управление комнатами и запись встреч):

- **Hiring Service** хранит бизнес-сущность `Interview`, создаёт комнату и запрашивает токен подключения через LiveKit API;
- **LiveKit** управляет медиа-сессией, а WebRTC-трафик идёт напрямую между браузером и LiveKit, минуя BFF и доменные сервисы.
