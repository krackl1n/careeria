# Документация Careeria

Careeria — рекрутинговая платформа полного цикла: профили кандидатов, вакансии, отклики, этапы найма, оценивание, коммуникации, видеособеседования, файлы и уведомления.

Документация описывает целевую модель проекта. Наличие сервиса на архитектурной схеме само по себе не означает, что его реализация уже завершена.

- [Начало работы](getting-started/index.md) — команды репозитория и запуск документации.
- [Описание проекта](readme.md) — исходное описание функций и технологической основы.
- [Архитектура](architecture/c4-plant-uml/plantuml/README.md) — C4, тематические проекции, области команды и сценарии.
- [Развёртывание](deployment/index.md) — команды запуска окружений.
- [Безопасность](security/index.md) — архитектурные правила доступа и проверки OpenFGA.
- [Как писать документацию](contributing.md) — Markdown, PlantUML и навигация.
