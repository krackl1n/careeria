# Начало работы

Для просмотра и редактирования документации нужен Docker с Compose. Node.js, Python и Java на рабочей машине не требуются.

Из корня репозитория:

```sh
make docs                  # Запуск сайта в контейнере и открытие браузера
make docs-build            # Статическая сборка в .site-docs/
make docs-test             # Строгая сборка и проверка схем/переходов
make docs-stop             # Остановка контейнера
```

MkDocs отслеживает изменения Markdown, PlantUML и конфигурации, пересобирает страницы и обновляет браузер. Изменение общего PlantUML include-файла автоматически инвалидирует только страницы с зависимыми диаграммами. Остановить сервер можно командой `make docs-stop`.

Локальные настройки находятся в `docs/.env`. Создайте его один раз из шаблона:

```sh
cp docs/.env.example docs/.env
```

Например, измените `DOCS_PORT=3000` или установите `DOCS_OPEN=0`. Если выбранный порт занят, `make docs` автоматически использует следующий свободный localhost-порт и выводит его. Файл игнорируется Git и не влияет на настройки других разработчиков.

При первом запуске Docker собирает образ из `docs/Dockerfile`: в нём находятся Python-зависимости из `docs/requirements.txt`, Java и закреплённый JAR PlantUML. Рендеринг выполняется внутри контейнера без публичного PlantUML-сервера.

Для остальных задач репозитория используйте `make help`. Требования к запуску самого приложения отличаются от требований к документации.
